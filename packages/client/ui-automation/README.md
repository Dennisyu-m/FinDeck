# @deepseek-ai/dsh-client-ui-automation

## Summary

`dsh-client-ui-automation` is the scheduled-tasks page. The name is the automation layer's page, the same role `automation-runner` schedules, not a second scheduler and not the settings switch. It registers one `settings.section` (`automation`) in the top nav. Disabling the Loader row `ui-automation` removes that entry on the next page load.
